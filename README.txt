23 Работа с ORM в Django
1. Подключить к проекту СУБД PostgreSQL, произвести необходимые настройки
2. Создать приложение с собаками. В приложении создать модели собаки и породы.
   Собака — с полями: имя, порода, фото, дата рождения. Порода с полями: название и описание.
3. Свяжите модель собаки с моделью породы через FK.
4. Настройте админку. В админку выведите id и название пород, а также имя и породу собак.
   Для собак добавьте фильтрацию по породам.
5. Создайте фикстуру для базы с помощью команды. Очистите базу и накатите фикстуру на чистую базу
6. Установите ipython и с помощью инструмента shell создайте породу и собаку с помощью прямого ORM запроса.
   Получите данные о собаке по имени (get). Выведите собак подходящих под определенные критерии (filter).
   Выведите все породы, которые записаны в БД (all)
